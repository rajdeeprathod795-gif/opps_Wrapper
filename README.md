# opps_Wrapper
Employee Management System
📖 About Project
This project is made using Python Object-Oriented Programming (OOP). In this project, I have used Person, Employee, and Manager classes to show how inheritance works in Python.

The main purpose of this project is to understand Classes, Objects, Constructor (_init_), Inheritance, Multilevel Inheritance, Methods, and the super() function.

✨ Features
Store Person details.
Create Employee using the Person class.
Create Manager using the Employee class.
Display all details in a simple format.
Use Multilevel Inheritance.
Use super() to call the parent class constructor.
🛠️ Technologies Used
Python 3
Object-Oriented Programming (OOP)
📚 Concepts Used
Class and Object
Constructor (_init_)
Inheritance
Multilevel Inheritance
super() Function
Methods
▶️ How to Run
Install Python 3.
Open the project in VS Code or any Python IDE.
Run the Python file.
The program will display the details of the Person, Employee, and Manager.

From this project, I learned how to use OOP concepts in Python. I understood how inheritance works, why we use the super() function, and how parent and child classes work together
